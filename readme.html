CIRCL Hash Lookup

This app queries the public CIRCL hashlookup service for information about MD5, SHA-1, and SHA-256 file hashes.

Configuration

The public CIRCL service does not require an API key. The app connects to:

https://hashlookup.circl.lu

Supported hashes

  • MD5 — 32 hexadecimal characters
  • SHA-1 — 40 hexadecimal characters
  • SHA-256 — 64 hexadecimal characters

Understanding the results

A match means the hash was found in one of CIRCL's indexed datasets. It does not by itself prove that the file is safe or malicious.

The hashlookup:trust value ranges from 0 to 100. A value of 50 is neutral. Values above 50 indicate that the file appears in more known sources.

Hash not found

A hash that is not present in CIRCL is returned as a successful lookup with found=false. Absence from the database does not mean the file is malicious or safe.

Action output data paths

The following data paths can be used in playbooks to access results returned by the file reputation action. Some fields are only present when CIRCL has that information.

Data path Type Description
action_result.status String Indicates whether the action succeeded or failed.
action_result.message String Human-readable result message.
action_result.summary.found Boolean true when CIRCL found the hash and false when no record was found.
action_result.summary.hash String The normalized hash submitted to CIRCL.
action_result.summary.hash_type String The detected hash format: md5, sha1, or sha256.
action_result.data.*.FileName String The known filename associated with the hash.
action_result.data.*.FileSize String The file size in bytes, when available.
action_result.data.*.MD5 String The MD5 hash associated with the file.
action_result.data.*.SHA-1 String The SHA-1 hash associated with the file.
action_result.data.*.SHA-256 String The SHA-256 hash associated with the file.
action_result.data.*.SHA-512 String The SHA-512 hash associated with the file.
action_result.data.*.source String The source dataset that supplied the record.
action_result.data.*.db String The CIRCL database containing the record.
action_result.data.*.hashlookup:trust Numeric CIRCL trust value from 0 through 100. This provides context and is not a malware verdict.
action_result.data.*.mimetype String The file's MIME type, when available.
action_result.data.*.ProductCode.ProductName String The software product associated with the file.
action_result.data.*.ProductCode.ProductVersion String The associated software product version.
action_result.data.*.PackageName String The package containing the file.
action_result.data.*.PackageVersion String The package version.
action_result.data.*.PackageDescription String A description of the package containing the file.
action_result.data.*.parents.*.PackageName String The name of a parent package associated with the file.
action_result.data.*.parents.*.PackageVersion String The version of a parent package.
action_result.data.*.parents.*.PackageDescription String A description of a parent package.

An asterisk (*) represents every item in a returned list. For example, parents.*.PackageDescription retrieves the description from each parent package returned by CIRCL.

Privacy

Hash values submitted to this action are sent to the public CIRCL hashlookup service.

Service availability

CIRCL provides the public hashlookup service on a best-effort basis.
